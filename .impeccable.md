## Design Context

### Users
Solo maker/hobbyist who 3D prints figures. Uses this as a personal workshop tool to track filament spools, figure designs, and a print queue. Context is hands-on crafting — likely used at a desk near a printer, sometimes on mobile to check what color to load next.

### Brand Personality
**Useful, warm, colorful.** A utilitarian workshop tool with a heart. Not cold and clinical — it should feel like a well-organized craft bench, not enterprise software. The filament colors themselves are the visual stars.

### Aesthetic Direction
- **Tone**: Warm utilitarian — functional first, but with craft-shop warmth. Think woodworking app, not SaaS dashboard.
- **Theme**: Light + dark mode (both supported, dark default). Blue-tinted OKLCH palette already in place.
- **Color philosophy**: Let the user's filament colors shine. UI chrome should be warm and recede; spool colors should pop. Tint neutrals warm rather than cool-gray.
- **Anti-references**: Generic SaaS dashboards, neon-on-dark "developer tool" aesthetics, glassmorphism, gradient text.
- **Typography**: Inter Variable is fine for a personal tool. Keep it clean and readable.

### Design Principles
1. **Colors are the content** — Filament spool colors are the visual centerpiece. UI should frame and amplify them, not compete.
2. **Workshop warmth** — Warm neutrals, generous but not wasteful spacing, tactile-feeling interactions. It should feel handmade, not generated.
3. **Utility first** — Every element earns its place. No decorative filler. But utility can still be beautiful.
4. **Accessible by default** — WCAG AA compliance. Proper contrast, focus indicators, semantic HTML, reduced-motion support.
5. **Mobile-ready** — Works at the printer with one hand on a phone. Touch targets matter.

### Accessibility
- WCAG AA target
- Reduced motion support (already implemented via `prefers-reduced-motion`)
- Color contrast awareness for light-on-light and dark-on-dark spool swatches (already handled with border fallbacks)
